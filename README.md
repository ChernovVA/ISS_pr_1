### Описание проекта
На данный момент задача состоит в корректном запуске виртуального просранства, выборе датасета для анализа и проведения разведочного анализа.

Выбранный датасет: https://www.kaggle.com/datasets/vijayaadithyanvg/car-price-predictionused-cars/data - предсказание цены автомобилей

### Порядок запуска проекта
После скачивания репозитария, в терминале, открытом в домашней папке, необходимо выполнить следующие команды: 

```
python3 -m venv .venv_Pr_1 //создание виртуального пространства

source .venv_Pr_1/bin/activate //активация виртуального пространства

pip install -r requirements.txt //загрузка необходимых библиотек
```

Для запуска MLflow необходимо в директории ./mlflow выполнить команду:

```
sh start_mlflow.sh
```

### Первоначальный анализ датасета
Датасет содержит 301 запись о продажах автомобилей. После очистки от дубликатов и неинформативных признаков (2 машины с ГБО) осталось 297 записей. Пропусков значений или несоответствия значений действительности (отрицательные значения пробега, количества владельцев, цен) не обнаружено.

В ходе разведочного анализа данных был создан интерактивный график для просмотра зависимостей между признаками. Наиболее информативными признаками являются год выпуска, пробег а также текущая цена нового автомобиля.

Было решено заменить признак "Год выпуска" на "Возраст", приняв за текущий год максимальное из представленных значений (2018).
 
При этом неинформативным признан признак количества владельцев, так как ненулевое значение он имеет только у 11 машин.

Более подробные выводы о разведочном анализе представленны в блокноте eda.ipynb.

### Создание микросервиса предсказаний

С использованием обученной ранее модели был создан микросервис предсказаний.
Для реализации API используется FastAPI, для запуска веб-сервера - Uvicorn. Сервис упакован в Docker-образ на основе Python 3.11.
Все необходимое для его работы находится в папке services:
- ml_service/main.py - создание FastAPI-приложения, описание GET- и POST-эндпоинтов, валидация входных данных.
- ml_service/api_handler.py - класс FastAPIHandler, отвечающий за загрузку модели и получение предсказаний.
- ml_service/requirements.txt - необходимые для работы микросервиса библиотеки.
- ml_service/Dockerfile - инструкции для сборки Docker-образа.
- models/get_model.py - скрипт загрузки модели из MLflow.
- models/model.pkl - рабочая модель.

#### Сборка Docker-образа и запуск контейнера

Из папки services/ml_service выполнить команду:

sudo docker build -t car-price-predict-service:1 .

Команда для запуска:

sudo docker run --rm --name car-price-api -p 8000:8000 -v "$(pwd)/../models:/models:ro" car-price-predict-service:1


#### Проверка работоспособности микросервиса

`http://localhost:8000/docs` - сайт для проверки

Сервис предоставляет два эндпоинта:

- `GET /` — возвращает `{"Hello": "World"}`.
- `POST /api/prediction` - принимает идентификатор автомобиля и его характеристики, возвращает предсказанную цену.

Пример POST-запроса:

URL: `http://localhost:8000/api/prediction?item_id=67`

Тело запроса:

{
  "Age": 3,
  "Present_Price": 5,
  "Driven_kms": 100000,
  "Fuel_Type": "Diesel",
  "Selling_type": "Dealer",
  "Transmission": "Manual"
}


Ответ:

{
  "item_id": 67,
  "price": 3.7774390243902447
}
